# Notebooks

This folder contains the final Google Colab notebooks used for the project:

**Per-Class Analysis of Semantic Segmentation Degradation Under Adverse Urban Driving Conditions**

The notebooks are organized in execution order:

1. `01_Setup_and_Data.ipynb`  
   Sets up the project folders, verifies the datasets, and prepares the project configuration.

2. `02_Model_and_Cityscapes.ipynb`  
   Loads the pretrained SegFormer-B2 model and evaluates it on the Cityscapes validation set.

3. `03_ACDC_Evaluation.ipynb`  
   Evaluates the original SegFormer-B2 model on the ACDC adverse-condition validation data.

4. `04_Per_Class_Analysis.ipynb`  
   Computes per-class IoU and class-specific degradation across fog, rain, snow, and night.

5. `05_Visualizations.ipynb`  
   Generates the main plots and qualitative visual examples used in the analysis.

6. `06_Matched_ACDC_Analysis.ipynb`  
   Performs matched normal-to-adverse ACDC analysis using the available scene correspondences.

7. `07_Class_Group_Vulnerability.ipynb`  
   Analyzes the Static Thin, Dynamic Small, and Large/Structural diagnostic class groups.

8. `08_Bootstrap_Confidence_Intervals.ipynb`  
   Applies paired bootstrap resampling to evaluate the stability of the matched degradation results.

9. `09_Modified_Model_Training.ipynb`  
   Recomputes the diagnosis using ACDC training correspondences only, creates vulnerability-aware training weights, and trains the modified SegFormer-B2 model.

10. `10_Modified_Model_Evaluation.ipynb`  
    Compares the original and modified SegFormer-B2 models on the untouched ACDC validation split.

11. `11_Paired_Bootstrap_Model_Improvement.ipynb`  
    Performs paired bootstrap analysis of the final original-versus-modified model improvement.

Dataset Access

The project uses:

Cityscapes
Link: https://www.cityscapes-dataset.com/

ACDC — Adverse Conditions Dataset with Correspondences
Link: https://acdc.vision.ee.ethz.ch/

## Running the Notebooks

The notebooks were developed and executed using Google Colab.

For the training and evaluation notebooks, a GPU runtime is recommended.

The notebooks should be executed in numerical order from Notebook 01 to Notebook 11 because later notebooks use outputs generated by earlier stages.
